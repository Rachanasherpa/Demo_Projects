# My Demo Projects

## SQL Project: Employee Database
A simple SQL script that:-
- Creates an Employees table
- Inserts sample records
- Runs a query to filter employees by department and salary.

## SQL Project: Sales and Customers Insights
- Queries for:-
  - Total sales per region
  - Top customer by sales
  - Average order value per customer

## Python Project: Random Number Guessing Game
A beginner-friendly Python script using the random module:
- Generates a random number between 1 and 10
- Let the user guess
- Displays whether the guess is correct

## Python Project: Automated Report Generator
- Generates random transaction data
- Saves results into a CSV file
- Demonstrates automation and reporting concepts
